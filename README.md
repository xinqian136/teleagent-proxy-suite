# TeleAgent 反代 v4 · Web 版

> **v4 = v3 + 视觉自动降级 + 模型别名**
>
> 网关的模型路由是动态的：同一个模型名，有时支持视觉、有时被路由到只支持文本的后端。
> 表现形式还会变 —— 可能是 `400 Model only supports text input`，
> 也可能是 200 但模型答「我无法查看图片」。靠检测错误再降级不可靠。
>
> **v4 提供模型别名 `chat-flagshipAuto`**：
>
> | 请求内容 | 实际发给网关 |
> |---|---|
> | 带图片 | `chat-flash`（视觉稳定） |
> | 纯文本 | `chat-flagship`（旗舰） |
>
> 客户端模型下拉里选 `chat-flagshipAuto` 就行，不用管网关当天怎么路由。
> 带图用哪个模型可在网页「设置」页改。
>
> 另外还保留了错误触发式降级（遇到「模型不支持视觉」的报错自动换 chat-flash 重试），
> 开关在「设置」页：**模型不支持图片时自动降级到 chat-flash**。
>
> | | v3 | v4 |
> |---|---|---|
> | 反代端口 | 8792 | **8793** |
> | Web 后台 | 8795 | **8796** |
> | 计划任务 | TeleAgent Proxy V3 | **TeleAgent Proxy V4** |
> | 账号数据 | `data/` | `data/`（独立） |
>
> v3 与 v4 **不要同时跑同一个账号**（同一 token 两处用，有封号风险）。

所有操作都在浏览器里点。不用记命令，不用改配置文件。

## 怎么暂停

三种粒度，按需要选：

| 想做什么 | 怎么做 |
|---|---|
| **暂停反代**（后台还在，网页能访问） | 网页「反代」页 → 点**暂停** |
| **恢复反代** | 网页「反代」页 → 点**恢复** |
| **停掉整个后台** | 双击 `暂停后台.cmd` |
| **重新拉起后台** | 双击 `启动后台.cmd` |

### 「暂停」和「停止」的区别

- **停止**：只是这次不跑，重启后台后反代会自己起来
- **暂停**：状态写进设置，**重启后台后也不会自动启动**，要手动点「恢复」

暂停了想让它下次开机照常自动起？在「恢复」之前把设置里的暂停关掉即可。

## 网页上能做什么

### 概览

- 反代服务状态、账号池状态、运行时长
- **客户端配置**：点「复制配置」直接复制三行，粘到 Cherry Studio / Cline / Cursor 就行
- 点「各客户端填法」看每个客户端具体在哪填
- 快捷操作：扫描本机账号 / 启停反代

### 账号

| 操作 | 怎么做 |
|---|---|
| 扫描本机 | 点「扫描本机」，自动找到 TeleAgent 的账号 |
| 导入 | 点「导入」，上传 `.bundle` 或填服务器路径 |
| 导出 | 点「导出」，选 bundle / Excel / CSV |
| 改备注 | 点「编辑」 |
| 启用/禁用 | 点「禁用」/「启用」 |
| 删除 | 点「删除」 |

### 反代

- 启停反代
- **对话测试**：填个消息直接发，看通不通
- 各个端点地址一览

### 设置

- **监听端口**：改了自动重启反代生效
- **监听地址**：默认只听本机，要局域网访问改成 `0.0.0.0`
- **API Key**：自定义，改了自动重启生效
- 存储类型：加密 JSON（默认）/ SQLite（需 Node 22+）
- 续期参数：检查间隔、提前多久续

### 日志

实时日志，每 4 秒自动刷新。

## 换机器用

**源机**：账号页 →「导出」→ 得到 `.bundle`（含 token + 渠道密钥）

**目标机**：
1. 把**整个文件夹** + `.bundle` 拷过去
2. 双击 `启动后台.cmd`
3. 网页上「导入」，选那个 `.bundle`

目标机**不需要装 TeleAgent**，不需要 `npm install`，只要有 Node 18+。

## 技术要点

- **零第三方依赖**：只用 Node 内置模块，前端零构建（原生 JS）
- **单端口三用**：一个进程同时是管理界面、管理 API、反代 API
- **热重载**：改端口/API Key → 反代自动重启生效，不用重启后台
- **反向代理**：管理后台自己也能当反代的入口，`/v1/*` 直接转发

## 注意

- 别删 `data/` —— 续期链靠它
- 管理后台默认只听 `127.0.0.1`。改成 `0.0.0.0` 就能局域网访问，
  但**任何人都能操作你的账号**，请自行评估
- 90 天后需要重新登录一次（服务端硬期限）
- 使用者需自行确保符合所使用服务商的服务条款
