# TeleAgent 反代套件（monorepo）

把桌面 AI 客户端的模型能力，暴露成任何 IDE / 脚本 / Agent 框架都能填的一行地址。

本仓库是**四个迭代版本的全量合集**：每个版本一个独立子目录，**保留完整 git 历史**，
并配一套讲清原理的文档 —— 目标是让你**看懂之后自己搭一个中间层**，而不是只能直接用我们这份。

```
teleagent-proxy-suite/
├─ docs/            ← 原理文档（先读这里）
├─ versions/        ← 四个版本的源码，各自带完整 git 历史
│  ├─ v1/           ← 双链路原型：内核链路 + 直连网关链路
│  ├─ v2/           ← 模块化：账号池 / 凭证自续期 / 可迁移
│  ├─ v3/           ← Web 管理后台 + 真流式 + 多模态
│  └─ v4/           ← 视觉自动降级 + 模型别名（当前推荐）
└─ tools/           ← 辅助脚本
```

---

## 这个项目在解决什么问题

TeleAgent（电信 AI「超级智能体」桌面端）有模型能力，但只有 GUI能用。
你想在 Cursor / Cline / Claude Code / Cherry Studio / WorkBuddy 里用它，就得让这些客户端
能说 OpenAI 或 Anthropic 的话。

**中间层反代**就是那个翻译器 + 调度器：

```
你的 IDE / Agent                中间层反代                     上游
┌────────────────┐      ┌──────────────────────┐      ┌──────────────┐
│ OpenAI 协议    │─────▶│ ① 协议转换            │      │              │
│ Anthropic 协议 │─────▶│ ② 凭证管理（多账号）  │─────▶│  云网关      │
│ Responses 协议 │─────▶│ ③ 签名                │      │              │
│                │      │ ④ 视觉能力适配        │      │              │
│                │      │ ⑤ 故障降级            │      │              │
└────────────────┘      └──────────────────────┘      └──────────────┘
      客户端                      本仓库                         网关
```

五个环节，每一环都能单独拆出来看，文档里逐个讲：

| 环节 | 文档 | 核心文件 |
|---|---|---|
| 协议转换 | [01](docs/01-协议转换.md) | `lib/proxy/api.js` |
| 凭证与账号池 | [03](docs/03-凭证与账号池.md) | `lib/proxy/pool.js` `lib/proxy/refresher.js` |
| 签名 | [02](docs/02-签名与鉴权.md) | `lib/proxy/signer.js` |
| 视觉适配 | [04](docs/04-视觉与降级.md) | `lib/proxy/media.js` |
| 流式 | [05](docs/05-流式与SSE.md) | `lib/proxy/sse.js` |
| 故障降级 | [04](docs/04-视觉与降级.md) | `lib/proxy/server.js` |

## 版本谱系

| 版本 | 定位 | 反代端口 | Web 后台 | 状态 |
|---|---|---|---|---|
| [v1](versions/v1/) | 双链路原型：内核链路（低风险）/ 直连网关链路（支持自定义 tools） | 8788 / 8790 | — | 历史归档 |
| [v2](versions/v2/) | 模块化重写：账号池、凭证自续期、加密存储、可打包迁移 | 8792 | — | 历史归档 |
| [v3](versions/v3/) | 加 Web 管理后台，所有操作网页点；修复流式与多模态 | 8792 | 8795 | 可用 |
| [v4](versions/v4/) | v3 + 视觉自动降级 + `chat-flagshipAuto` 模型别名 | 8793 | 8796 | **推荐** |

**v4 是当前推荐版本**，目录在 `versions/v4/`。

## 快速跑起来（v4）

前置：Windows + Node.js 18+，装了 TeleAgent 并登录过（提供凭据）。

```cmd
cd versions\v4
:: 双击 启动后台.cmd，或手动：
node bin\tav3.js web
```

浏览器打开 `http://127.0.0.1:8796/`，在「账号」页点「扫描本机」，然后「反代」页点启动。

客户端填三行：

```
Base URL : http://127.0.0.1:8793/v1
API Key  : teleagent-local
Model    : chat-flagshipAuto      ← 带图自动降级；纯文本也推荐用这个
```

详细步骤见 [v4 README](versions/v4/README.md) 和 [06 · 部署与运维](docs/06-部署与运维.md)。

## 自己搭一个（这才是重点）

这份代码不试图成为「唯一实现」。文档 [07 · 自建中间层指南](docs/07-自建中间层指南.md)
按**最小可用 → 逐项加固**的顺序拆解，每一步都给出：

- 要做什么、为什么
- 关键代码（可直接抄）
- 怎么验证这一步做对了
- 常见的坑（都是本项目实际踩过的）

如果你要接的是**别的**上游（不是 TeleAgent），把 [01](docs/01-协议转换.md)、
[02](docs/02-签名与鉴权.md)、[05](docs/05-流式与SSE.md) 当模板，
[03](docs/03-凭证与账号池.md) 和 [04](docs/04-视觉与降级.md) 当反面教材清单照着避坑。

## 各版本的 git 历史

每个版本子目录都是一次 `git subtree add` 合入的，**原始提交全部可达**：

```bash
cd versions/v3
git log --oneline          # 这个目录的完整历史
git log --oneline -- lib/proxy/sse.js    # 单文件演进
```

合并后的整体历史：

```bash
git log --oneline --graph --all
```

想看某个版本从哪个提交分叉：

```bash
git log --oneline -- versions/v4
```

## 依赖与运行环境

| 项 | 说明 |
|---|---|
| Node.js | 18+。**零第三方依赖**，只用 Node 内置模块 |
| Python | 仅 v1 需要（提取 sessionKey 的逆向脚本用），v2+ 不需要 |
| 平台 | Windows（DPAPI 解密依赖 Windows 凭据保护）；核心协议层是纯 Node，理论上可移植 |
| TeleAgent | v1 需要；v2+ 通过账号包迁移，目标机可不装 |
