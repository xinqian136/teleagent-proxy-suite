# TeleAgent 反代 v3 · Web 版

所有操作都在浏览器里点。不用记命令，不用改配置文件。

---

## 启动

**双击 `启动后台.cmd`** → 浏览器自动打开 `http://127.0.0.1:8795/`

就这一件事。剩下的全在网页上。

---

## 网页上能做什么

### 概览

- 反代服务状态、账号池状态、运行时长
- **客户端配置**：点「复制配置」直接复制三行，粘到 Cherry Studio / Cline / Cursor 就行
- 点「各客户端填法」看每个客户端具体在哪填
- 快捷操作：扫描本机账号 / 启停反代

### 账号

| 操作 | 怎么做 |
|---|---|
| 扫描本机 | 点「扫描本机」，自动找到 TeleAgent 的账号 |
| 导入 | 点「导入」，上传 `.bundle` 或填服务器路径 |
| 导出 | 点「导出」，选 bundle / Excel / CSV |
| 改备注 | 点「编辑」 |
| 启用/禁用 | 点「禁用」/「启用」 |
| 删除 | 点「删除」 |

### 反代

- 启停反代
- **对话测试**：填个消息直接发，看通不通
- 各个端点地址一览

### 设置

- **监听端口**：改了自动重启反代生效
- **监听地址**：默认只听本机，要局域网访问改成 `0.0.0.0`
- **API Key**：自定义，改了自动重启生效
- 存储类型：加密 JSON（默认）/ SQLite（需 Node 22+）
- 续期参数：检查间隔、提前多久续

### 日志

实时日志，每 4 秒自动刷新。

跑一次 `scripts\install-task.cmd`，登录后自动起。

## 换机器用

**源机**：账号页 →「导出」→ 得到 `.bundle`（含 token + 渠道密钥）

**目标机**：
1. 把**整个文件夹** + `.bundle` 拷过去
2. 双击 `启动后台.cmd`
3. 网页上「导入」，选那个 `.bundle`

目标机**不需要装 TeleAgent**，不需要 `npm install`，只要有 Node 18+。

## 目录

```
teleagent-proxy-v3/
├─ 启动后台.cmd        ← 双击这个
├─ bin/tav3.js         入口
├─ lib/
│  ├─ web/             Web 后台
│  │  ├─ server.js       路由：/ 界面  /api/admin/* 管理  /v1/* 反代
│  │  ├─ manager.js      反代生命周期（可热启停）
│  │  ├─ settings.js     设置持久化
│  │  └─ public/         前端（零构建单页）
│  ├─ account-manager/ 扫描/导入/导出
│  ├─ storage/         加密 JSON / SQLite
│  └─ proxy/           签名/网关/账号池/续期
├─ config/settings.json  设置（网页上改这里）
└─ data/                凭据（别删）
```

---

## 技术要点

- **零第三方依赖**：只用 Node 内置模块，前端零构建（原生 JS）
- **单端口三用**：一个进程同时是管理界面、管理 API、反代 API
- **热重载**：改端口/API Key → 反代自动重启生效，不用重启后台
- **反向代理**：管理后台自己也能当反代的入口，`/v1/*` 直接转发

---

## 注意

- 别删 `data/` —— 续期链靠它
- 管理后台默认只听 `127.0.0.1`。改成 `0.0.0.0` 就能局域网访问，
  但**任何人都能操作你的账号**，请自行评估
- 90 天后需要重新登录一次（服务端硬期限）
- 使用者需自行确保符合所使用服务商的服务条款
